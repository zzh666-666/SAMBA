# 000300.SH 扩充适配 SAMBA 图结构方案

## 1. 设计目标

把 `000300.SH-行情统计.xlsx` 扩充成一个更适合 SAMBA 图结构的多因子日频数据集，使其尽量接近现有美股 `82` 维特征结构，并提高图卷积的可学习性。

## 2. 先明确 SAMBA 的图是怎么建的

从 `SAMBA/models/samba.py` 和 `SAMBA/models/graph_layers.py` 可以看出，SAMBA 的“节点”本质上是**特征维度**，不是股票列表。

所以：

- `1` 个沪深300主序列不够
- 需要把 `000300.SH` 扩成一个“多特征节点图”
- 每一列特征都可以看成一个节点

因此，最优策略不是做“单价序列预测”，而是构造：

`沪深300主行情 + 相关市场 + 宏观利率 + 汇率 + 商品 + 风格因子 + 技术因子`

## 3. 扩充原则

### 3.1 节点优先级

按优先级分三层：

1. **核心节点**：直接由沪深300行情重算，必须保留
2. **高价值外部节点**：Wind 可稳定补齐，强烈建议加入
3. **派生节点**：由基础序列组合或滚动计算得到

### 3.2 目标维度

建议最终做成两种版本：

- **基础版**：`15~25` 维，先跑通流程
- **完整版**：`81~82` 维，尽量对齐美股数据集

## 4. 推荐的特征图结构

### 4.1 核心市场节点（15 个）

这部分完全由 `000300.SH-行情统计.xlsx` 构造：

- `Price`
- `Vol.`
- `weekday`
- `mom`
- `mom1`
- `mom2`
- `mom3`
- `ROC_5`
- `ROC_10`
- `ROC_15`
- `ROC_20`
- `EMA_10`
- `EMA_20`
- `EMA_50`
- `EMA_200`

说明：

- `Price` 使用收盘价
- `Vol.` 使用成交量
- 其余技术因子全部由 `Price` 重算

### 4.2 中国本土增强节点（建议 10~20 个）

这类节点最适合增强沪深300自身解释力：

- 前收盘价
- 开盘价
- 最高价
- 最低价
- 涨跌
- 涨跌幅
- 均价
- 换手率
- A股流通市值
- 总市值
- A股流通股本
- 总股本
- 市盈率
- 市净率
- 市销率
- 市现率

这些字段来自原 Excel，不需要额外数据源。

### 4.3 跨市场联动节点（建议 20~25 个）

优先从 Wind 补齐，尽量模仿美股数据里的跨市场结构：

- 上证指数、深证成指、创业板指
- 中证500、中证1000
- 恒生指数、国企指数、恒生科技
- 日经225、韩国综合
- 德国DAX、法国CAC、英国FTSE
- 标普500、纳指、道琼斯、罗素2000

用途：

- 提供全球风险偏好和外部冲击信息
- 让沪深300的图节点具备“跨市场关系”

### 4.4 宏观金融节点（建议 15~20 个）

优先补这些：

- 中国国债收益率曲线
- 中美利差
- SHIBOR / LPR / DR007
- 美国10年期、5年期、2年期、3个月利率
- 信用利差
- 美元指数
- 主要汇率

用途：

- 增强图模型对资金面和利率周期的感知

### 4.5 商品与风格节点（建议 10~15 个）

建议补：

- 原油（WTI / Brent）
- 黄金、白银、铜
- 天然气
- 小麦
- 波动率指数（如可得）

用途：

- 提供通胀、避险和商品周期信息

## 5. 最佳扩充方案

### 方案 A：最稳妥的 15 维基础版

适合先验证 SAMBA 流程：

- 只用沪深300 Excel
- 重算技术指标
- 不补外部市场

优点：

- 实现快
- 缺失少
- 便于排查代码问题

缺点：

- 图结构信息不足
- 与原美股 82 列差距大

### 方案 B：推荐的 40~60 维增强版

适合大多数实验：

- 沪深300主行情 15 维
- 估值/市值/换手等本地增强节点 10~15 维
- 中国主要宽基与行业指数 10~15 维
- 少量宏观/汇率/商品因子 10~15 维

优点：

- 对中国市场更贴合
- 数据源压力适中
- 比基础版更适合图学习

### 方案 C：最接近美股的 82 维完整版

适合做强对齐实验：

- 保留沪深300本地节点
- 用 Wind 补齐全球指数、商品、汇率、利率、信用利差、美股龙头
- 尽量复刻美股 CSV 的列族结构

优点：

- 最接近现有 SAMBA 论文数据形态
- 最适合直接复用现有训练配置

缺点：

- 依赖 Wind 数据整理
- 对齐成本最高

## 6. 节点构造建议

### 6.1 不建议直接把“股票代码”当节点

因为 SAMBA 当前实现的图是特征图，不是证券图。

所以对 `000300.SH` 最好按“特征节点”扩充，而不是把很多股票拼成一个横截面图。

### 6.2 推荐节点分组

建议最终把节点分成 5 组：

- `core_market`
- `china_enhanced`
- `global_equity`
- `macro_rates_fx`
- `commodities`

这样后续做解释和消融实验都更方便。

## 7. 处理规则

- 所有外部序列统一到交易日历
- 缺失值优先前向填充，再做截断
- 对齐前统一为同一频率和同一时区口径
- 价格类字段做归一化或 Min-Max 缩放
- 估值/利率/汇率类字段保留原始相对变化更有利

## 8. 最推荐的落地路径

1. 先用 `000300.SH-行情统计.xlsx` 构建 `15` 维基础版
2. 再加入中国本土增强节点，扩到 `30+` 维
3. 最后用 Wind 补齐跨市场与宏观节点，冲到 `82` 维
4. 保持列名、顺序和缺失处理规则尽量贴近现有美股数据

## 9. 结论

要让 `000300.SH` 最佳适配 SAMBA 图结构，核心不是“多加几列”，而是把它扩成一个**特征之间可建图的多因子面板**。

最优形态是：

`沪深300主行情 + 本地技术/估值/市值因子 + 中国宽基/行业指数 + 全球市场联动 + 宏观利率/汇率/商品`

这样最接近 SAMBA 当前“特征节点图”的建模方式。
