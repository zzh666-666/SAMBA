## 2. 模型构造层面的创新点（可写入“方法创新”）

### 2.1 双向 Mamba 的时序建模（BI-Mamba）

- 论文核心思想：同时处理正向序列与反向序列，融合后再做残差归一化与 FFN，提升长依赖建模能力。  
- 本项目实现对应：
  - `models/mamba.py` 中 `self.layers` 与 `self.layers2` 分别处理正向/反向；
  - 每层融合形式为：`x = x1 + x2.flip([1]) + x`，再过 `self.lin[i]` 做序列维度非线性映射；
  - `paper_config.py` 当前主配置：`d_model=64, d_state=64, n_layer=3`。

### 2.2 自适应图卷积（AGC）建模特征间关系

- 论文核心思想：将每日特征视作图节点，用可学习嵌入构图，避免固定先验图。
- 本项目实现对应（`models/samba.py`）：
  - 可学习节点嵌入：`adj ∈ R^{N×de}`（`de=10`）；
  - 高斯核构图：由节点嵌入欧氏距离生成邻接矩阵，并行归一化（`softmax`）；
  - 切比雪夫多项式图卷积：`cheb_k=3`；
  - 采用参数池 `weights_pool/bias_pool` + 节点嵌入投影生成节点自适应卷积核，等价于论文中的“低秩/因子化”思想，减少参数冗余。

### 2.3 时序块 + 图块的串联耦合

- 先用 Mamba 提取时间依赖，再用 AGC 抽取跨特征关系，最后线性投影到一步预测值。  
- 这种“时序先行、图结构增强”的耦合路径，是 SAMBA 相比单纯 Mamba 或单纯 GNN 的关键结构创新。

## 3. 数据处理与任务定义的关键细节（可写入“数据与预处理”）

### 3.0 论文实验任务（补充）

结合论文第 II、IV 节，实验任务可明确拆分为 4 类：

1. **主预测任务（核心）**  
   给定过去 \(L\) 天的多特征输入 \(X\in\mathbb{R}^{L\times N}\)，预测下一交易日的 **1-day return ratio**：  
   \[
   o_{L+1}=\frac{c_{L+1}-c_L}{c_L}
   \]
   其中 \(L=5\)、\(N=82\)（论文实验设置）。

2. **跨市场泛化任务**  
   在 3 个美国市场数据集（NASDAQ、NYSE、DJIA）上分别训练与评估同一模型框架，检验方法在不同市场分布下的稳定性。

3. **与 SOTA 基线的对比任务**  
   与 LSTM、Transformer、FreTS、StockMixer、AGCRN、FourierGNN、MambaStock 等方法做统一对比，验证 SAMBA 的预测优势。

4. **计算效率评估任务**  
   除预测精度外，额外评估训练效率与复杂度，指标包括 **training time per epoch** 与 **MACs**（并报告参数量）。

### 3.1 数据与任务

- 数据集：NASDAQ、NYSE、DJIA 三个市场，时间覆盖 **2010-01 到 2023-11**，每条样本含 82 个日频特征（论文设定）。
- 任务目标：一步预测，并以收益率相关指标（IC/RIC）评估排序与相关性能力。

### 3.2 本项目预处理流程（`utils/data_utils.py`）

1. 读入 CSV（`Date` 作为索引），删除 `Name` 列。  
2. 构造辅助方向特征：  
   `Target = (Price.pct_change().shift(-1) > 0).astype(int)`。  
3. 滑窗构造：`window=lag`，默认实验常用 `lag=5`（部分历史实验出现 `lag=10`）。  
4. 标签构造：预测目标为下一时刻 `Price`；输入为除 `Price` 外的全部特征（包含新增 `Target`）。  
5. 归一化：仅在训练段拟合 Min-Max，再作用于训练/验证/测试。  
6. 评估前逆归一化回价格，再换算收益率：
   \[
   r_t = \frac{c_t - c_{t-1}}{c_{t-1}}
   \]
   最终计算 MAE、RMSE、IC、RIC。

### 3.3 数据切分实现细节

- 当前项目主配置采用论文比例 `80%/5%/15%`（train/val/test）。  
- 实现上按时间段切片为：**前段 test，中段 train，末段 val**（代码中的切片逻辑），这是复现实验时必须明确记录的实现细节。

## 5. 可直接用于正文的“本文创新点”表述建议

1. **提出时空耦合的 Graph-Mamba 预测框架**：以双向 Mamba 捕获长时依赖，以自适应图卷积刻画特征交互，实现时间关系与特征关系联合建模。  
2. **引入可学习高斯核构图机制**：通过节点嵌入端到端学习邻接矩阵，避免静态先验图在金融场景下的偏置问题。  
3. **构建收益率导向的训练评估链路**：模型在价格空间训练与反归一化后，统一转到收益率空间评估 IC/RIC，更贴近交易排序目标。  
4. **形成可复现实验工程体系**：实现多数据集统一训练、历史结果追踪与配置留痕，支持对论文参数与工程参数进行可追踪对照优化。
