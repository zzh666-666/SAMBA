# 沪深300对齐美股数据集方案

## 目标

把 `000300.SH-行情统计.xlsx` 迁移成尽量贴近现有美股 `combined_dataframe_*.csv` 的多因子日频数据集，优先对齐到 **82 列 schema**：

- 15 个本地市场/技术指标
- 67 个外部跨市场与宏观因子

最终目标：

- 保留和现有 SAMBA 一致的 `Date / Price / Vol. / weekday / ...` 结构
- 让沪深300版本尽量可以直接复用当前训练流程

## 1. 对齐结论

### 1.1 仅靠这一个 Excel 能补齐多少

可直接构造出 **15 个本地指标**：

- `Price`
- `Vol.`
- `weekday`
- `mom`
- `mom1`
- `mom2`
- `mom3`
- `ROC_5`
- `ROC_10`
- `ROC_15`
- `ROC_20`
- `EMA_10`
- `EMA_20`
- `EMA_50`
- `EMA_200`

其中：

- `Price` 用 `收盘价`
- `Vol.` 用 `成交量(万股)` 或做过标准化后的成交量
- `weekday` 由 `交易日期` 计算
- 其余技术指标由 `Price` 序列重算

### 1.2 结合 Wind 后可对齐到多少

理论上可以对齐到 **82 列完整 schema**，但分成三种等级：

- `15/82`：仅用 Excel 就能做
- `70+ / 82`：Excel + Wind 大概率可补齐
- `82/82`：如果 Wind 能提供所有外部序列且日期口径一致，基本可做满

## 2. 字段映射方案

### 2.1 Excel 直接提供

| 美股字段 | 沪深300来源 | 处理方式 |
| --- | --- | --- |
| `Date` | `交易日期` | 改名并转日期索引 |
| `Price` | `收盘价` | 直接映射 |
| `Vol.` | `成交量(万股)` | 直接映射或标准化 |
| `weekday` | `交易日期` | 计算星期编码 |
| `mom*` | `Price` 序列 | 由收盘价重算 |
| `ROC_*` | `Price` 序列 | 由收盘价重算 |
| `EMA_*` | `Price` 序列 | 由收盘价重算 |

### 2.2 Wind 优先补齐

建议优先补齐以下 67 个外部因子：

- 全球股指与股指期货
- 美股龙头个股
- 外汇与美元指数
- 大宗商品与商品期货
- 美债、票据、信用利差

这些字段和现有美股数据最像，适合做“跨市场对齐”。

### 2.3 最难补齐

最难的是这类字段：

- `TE1`、`TE2`、`TE3`、`TE5`、`TE6`
- `DE1`、`DE2`、`DE4`、`DE5`、`DE6`

原因：

- 它们通常不是 Wind 的单一原生字段
- 更像是“由利率曲线或信用利差组合出来的派生特征”
- 需要先确认原论文/原仓库里对它们的精确定义，再用 Wind 底层序列复现

## 3. 推荐的实现顺序

### 阶段 A：先做 15 列本地版

先只用 Excel 生成一个沪深300版基础数据集，验证流程：

- 日期排序
- 缺失值处理
- 技术指标计算
- 训练流程能跑通

这一步最稳，适合先验证代码链路。

### 阶段 B：补齐高价值外部因子

优先补这几类：

1. 全球指数/期货
2. 外汇/美元指数
3. 商品/商品期货
4. 美债和信用利差
5. 美股龙头股

这一步能把数据从“本地指数预测”升级成“跨市场因子预测”。

### 阶段 C：补派生利差因子

最后处理 `TE*`、`DE*`：

- 如果 Wind 有同口径字段，直接取
- 如果没有，就用 Wind 的底层序列自行组合
- 如果定义不明确，建议暂时剔除或替换为近似因子

## 4. Wind 可补的内容

Wind 适合补这几类数据：

- 指数历史行情
- 期货历史行情
- 个股历史行情
- 外汇历史行情
- 债券/利率/收益率曲线
- 宏观经济指标

对这个项目最实用的是：

- `沪深300` 以外的中美欧日港韩主要指数
- 商品期货和能源价格
- 美元指数及主要汇率
- 美国短端利率、长端利率、信用利差
- 美股龙头股

## 5. 最终建议

如果目标是“最大程度对齐美股数据集”，建议最终保留 **82 列结构**，其中：

- `15` 列来自沪深300 Excel 重建
- `67` 列由 Wind 补齐或重算

如果只追求“先跑通并尽量接近”，先做 **15 列基础版**，再逐步扩展到 **82 列完整版**。

## 6. 风险提示

- Wind 字段名和原美股列名不一定一一对应
- `TE*`、`DE*` 需要先核对定义
- 不同市场交易日不完全一致，最终仍要统一日历并处理缺失
- `持仓量` 当前为空，不能作为有效特征

## 7. 结论

这份沪深300 Excel 作为“主序列”是够用的；要做到和美股数据集高度对齐，关键不在主序列，而在外部因子补齐。

最优路径是：

`沪深300主行情 + Wind跨市场因子 + Wind宏观利率/商品/外汇 + 自行重算技术指标`

这样最接近现有 SAMBA 的 82 列结构。
